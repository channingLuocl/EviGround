## 原因证据

- 原始 v8.0 有 0 个 API 错误；原始响应 usage 包含图像 tokens，图片已发送。
- mini fridge、window、computer tower 三个严重错例逐点包围盒与 GT OLT 最大误差均小于
  0.000001 米，没有发现实例 ID／点云错位。
- 原图每个物体只占 512 像素格的一小部分，半径 1 像素的稀疏十字点导致表面和轮廓断裂。
- 只调整取景、点圆盘与多图输入的固定 12 个样本仍为 3/12，不能把成像假说当作完整解释。
- 原始表面连接、场景上下文、尺寸／离地高度共同改善识别；例如 scene0565_00 #31
  从 chair 改为 window，但 mini fridge 仍识别为 cabinet，说明分类能力与类别粒度仍有问题。
- chair/office chair、table/desk、plant/potted plant 等近义／上下位类别仍按原规则区分，
  未通过修改评分把错误改成正确。

## 实现范围

1. 三个孤立视角按投影点覆盖选取，保持 90 度间隔并自动取景。
2. 优先读取原始 ScanNet 三角面，核对顶点顺序、轴对齐坐标与 RGB 后深度渲染；
   仅在实测三角面内插值颜色，不补全缺失几何。没有网格时记录点圆盘回退模式。
3. 上下文扩大并从房间内部方向观察；输入实测尺寸、估计离地高度。
4. 请求发送四张独立图片，拼图仅供人工审查；schema 用共享类别定义减少重复枚举。
5. 修复提前停止时尚未开始的场景目录不存在导致汇总导出失败的问题。
   验证过程仅迁移过这一项非推理改动的检查点哈希，旧 config 与说明均保存。

GT 类别、作者类别和查询不进入推理。网格模式额外使用原始面连接，不能声称严格只有点坐标输入。
v7 定位器和共享 API 客户端均未修改。

## 300 个实例完成后的复核（2026-10-16）

| 固定实例范围 | v8.1 正确数 | 作者发布标签正确数 |
| --- | ---: | ---: |
| 原开发集 100 个 | 45 / 100 = 45% | 72 / 100 = 72% |
| 新增 200 个 | 82 / 200 = 41% | 126 / 200 = 63% |
| 合计 300 个 | 127 / 300 = 42.33% | 198 / 300 = 66% |

同批、同评分规则下落后作者 23.67 个百分点。新增 200 个也低于作者，当前
“渲染后让 VLM 独立赋类”的实现尚未达到替换作者分类器的目标。42.33% 是类别
预测准确率，与 v7.4 的最终定位准确率不是同一指标。

只有 1 个接口／schema 错误、5 个完成但无法识别的预测，共 6 个 null。
即便全部 null 都改对，上限也只是 133 / 300 = 44.33%；错误重试不能解释或解决主要差距。
唯一 schema 错误是 scene0670_00 #34：返回的 alternatives 包含公共词表外的 apron；
主预测是 clothes，GT 为 picture。即使接受这次格式不合规的答案，该例仍是识别错误。
目前没有证据将这些语义错误归因于 10 本地／8 API 并发。

配对结果：两者都正确 102 个，只有作者正确 96 个，只有 v8.1 正确 25 个，
两者都错 77 个。说明 v8.1 有互补证据，但直接整体替换损失更大；不能用 GT
判断什么时候采用哪个答案。主预测或最多 3 个 alternatives 中命中 GT 共 176 个，
仅为可变长度候选列表的离线诊断，不能作为分类准确率，也不是可用的答案选择策略。

错误同时包含粒度差异（chair→office chair 9 个、doorframe→door 4 个、
table→desk 4 个）和明显识别错误（window→chair 4 个、computer tower→office chair 2 个）。
后者不能靠合并类别名称修复。人工查看 scene0131_00 #30 的图像发现实例表面残缺、
上下文中的目标未显示可见 ID；scene0500_00 #26 的窗户虽然在上下文标出，仍被认成椅子。
这些是具体失败证据，尚不是每种渲染／提示组件的因果消融结论。

源码核对：作者 Nr3D 分类器是 PointNeXt 点云编码器＋学习到的 256→512 投影，
再与 CLIP 类别文本特征做相似度 argmax；不是仅靠手写规则或简单 VLM 看图。
依据为 prepare_data/process_feat_3d.py、models/pcd_classifier.py 与
prepare_data/object_lookup_table_nr3d.py。当前比较使用已发布类别，不是重新运行权重。
