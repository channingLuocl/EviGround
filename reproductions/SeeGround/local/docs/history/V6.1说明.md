# SeeGround v6.1

v6.1 保留 v6 的查询义务、局部候选图和主动证据流程，增加跨进程 API 限流。`--workers` 仍可设置为 32，用于并行加载场景、几何计算和 CPU 渲染；`--api-concurrency` 单独限制同时发往模型中转站的请求数。限流在统一的 `qwen_api._chat_once()` 请求入口生效，使用操作系统文件锁，因此覆盖批处理器启动的独立 worker 进程；请求异常或进程退出后锁会自动释放。

建议先使用 4 路 API 并发：

```bash
cd ~/paper-v6/reproductions/SeeGround
set -a
source /root/.config/seeground/relative-size-v2-relay.env
set +a

export PYTHONDONTWRITEBYTECODE=1
export PYTHONPATH=local
export OMP_NUM_THREADS=1
export OPENBLAS_NUM_THREADS=1
export MKL_NUM_THREADS=1
export NUMEXPR_NUM_THREADS=1
export VECLIB_MAXIMUM_THREADS=1

RUN_DIR="local_outputs/v6_1_relay_dev68_$(date +%Y%m%d_%H%M%S)"
.venv/bin/python -u local/run_size_validation.py \
  --manifest local/validation/v5_development_68.json \
  --scene-root /root/paper/reproductions/SeeGround/local_outputs \
  --output "$RUN_DIR" \
  --review-limit 3 \
  --workers 32 \
  --api-concurrency 4
```

如果中转站仍出现大量 `read timeout`，保留 `--workers 32`，把 `--api-concurrency` 降到 2；如果请求稳定但吞吐不足，再逐步提高到 6。每次运行使用独立的结果目录，批处理器会自动创建 `.api_slots` 锁目录并将并发配置写入 `manifest.json`。
