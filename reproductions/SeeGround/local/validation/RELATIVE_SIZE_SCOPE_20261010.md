# 相对大小支持范围：relative-size-v1

本轮仅修改大小语义、实例几何、必要的条件绑定及大小证据在规划器中的表达。为保住旧正向控制，既有裸色反证保护补齐 majority/dominant 和 not match the pure quoted color 的无依据覆盖／纯度措辞，只降为 unknown，不新增颜色判定能力。大小拆分后仍带否定的复合属性也保持 unknown：既有未支持的否定／排除谓词不能借外观 yes/no 排除候选或完成条件；独立颜色条件继续单独验证。原始源码和历史输出保留在原工作区，开发在独立分支 `codex/relative-size-evidence`。十条人工看过的样例及额外 longer 属于开发数据，不是独立测试集。

## 语义与门禁

- 原文及词形保留。普通 `small/large/big/little` 可声明采用上下文相对比较解释，要求完整绑定的同类池、至少两个可靠成员、明显且唯一的极值。
- `smaller/larger/bigger/taller/shorter/longer` 在两成员池中比较；三成员以上采用相关集合内明显较大／较小者的解释，要求唯一极值及预声明差距。`of the two` 还要求恰好两个完整绑定实例。
- 普通 `tall/short/high/low` 没有可靠描述属性判据，继续 unknown。并列不是“两者都高”的证明，位置唯一不能删除大小义务。
- 原句明确 `short ... between two tall ...` 时，恢复局部相对高度：目标低于两个不同参照，且在同一参照假设下满足 between。此规则不声称绝对“高”，也不要求全场景最矮。全部未被明确反证的参照组合保留。
- 每条条件从原句绑定并冻结自己的比较池。颜色、位置和关系不能把它改成剩余候选池；只有明确 `of the green ...` 才绑定颜色子集。未知成员不删除，已绑定成员变化或转未知会使大小证据 unknown。
- 普通诊断、主动 size 操作和零 API 重放均调用 `size_semantics.evaluate_size_condition()`。主动流程必须实际执行 size；外观操作中的测量预览不能解除大小义务。finish、预算耗尽及位置唯一均不能绕过 pending。
- 外观合取 no 不能在缺少独立类别结论时变成类别 no；属性和类别的反证分别记录。含未支持否定谓词的完整属性保持 unknown，不阻断独立颜色反证。规划器损坏 JSON 与截断回包一样属于无效动作：保留原回包、拒绝执行，消耗既有动作尝试预算，未获得证据；网络失败继续单列运行错误。
- 若仍有候选、预算可用，并且待完成的目标／参照大小条件已有明确的至少两成员范围，规划器不能在尚未执行 size 时声称没有可用证据而 stop：控制器提供现有 size 请求，仍由规划器执行。size 执行一次后即使结果 unknown 也允许 stop；描述性 tall、未绑定范围及预算耗尽不强制比较。重复无效 stop 仍受原动作尝试预算限制。

统一条件记录保留原文、来源、目标／参照角色、词形、解释、度量理由、范围／参照 IDs、冻结状态、逐候选 pass/fail/unknown、可靠性及并列／未知原因。联合证据的完整赋值保存在本地轨迹；规划器收到所有合法参照组合的摘要及候选证据，避免把重复审计回包塞入 API 请求。

## 度量与可靠性

| 条件 | 使用度量 | 依据与限制 |
| --- | --- | --- |
| taller/shorter | 重力方向 Z 高度，米 | 实例点云范围，不使用中心海拔，不混入其他实例的桌上物品；共同顶面但底部显著错层且无完整性认证时 unknown。 |
| longer | 水平定向长边，米 | XY 凸包最小面积矩形，不固定世界 X；水平旋转保持排序和判断状态。 |
| 门窗 small/large/smaller/larger | 竖直门窗面宽×高，平方米 | 薄竖面 PCA 支撑、宽高与覆盖要求；厚度不主导。结构依据不足时 unknown，不退回体积挑答案。 |
| 其它新普通大小／比较级 | 定向体积，立方米 | 定向底面积排序必须一致；缺可靠定向度量或代理冲突均 unknown。 |
| 原有整体大小最高级 | 原 AABB 体积与底面积 | 保留旧代理冲突保护，包含书本 34177；不以新规则重写历史成绩。 |

新增定向几何采用 float64 XY 凸包与最小面积矩形。可靠性逐度量记录算法、单位和原因：有限非退化尺寸不小于 0.02m；1%–99% 稳健跨度与完整跨度差不超过 max(0.05m,10%)；水平凸包支撑覆盖超过 0.50。门窗面要求 PCA 法向与重力近乎正交（abs(normal_z)≤0.15）、90% 厚度／短面边≤0.20、投影凸包覆盖>0.50。

点数只记录观测量，不证明扫描完整。缺点云、退化、边界不稳定或明显测量歧义时 unknown；通过上述检查也不是扫描完整性的独立认证。无法从类别判断桌面、缺失部件或物体固有方向。

## 预声明容差

差距必须严格大于 max(绝对容差，相对容差×两值绝对值的较大者)。

| 用途 | 相对容差 | 长度绝对容差 |
| --- | --- | --- |
| 测量并列／原最高级 | 5% | 0.02m |
| 明确比较级／局部高度对比 | 10% | 0.03m |
| 普通 small/large 上下文解释 | 20% | 0.05m |

面积绝对容差 0.005m²，体积 0.0005m³。规则和容差在开发阶段统一声明，不按场景、目标或 GT 调整。

## 保留的限制

near、固有朝向、未明确语言参照系的 behind、复杂未绑定比较子集、尚未绑定的显式 than 参照比较、绝对 tall/short、全扫描完整性认证和整个外观能力不在本轮扩展范围。错误接受保护继续优先于减少 missing；大小条件解决、整句正确接受、其它条件 missing 和正确候选误排分别报告。

混合 26 条验收在真实运行前预声明：9 条整句正向、13 条拒绝边界、4 条条件诊断；必须零错误接受／运行错误，所有排除都有明确 fail。完整 300 使用原固定清单、新目录、原每题 5 次证据预算和 4 workers；补跑单列，不拼接成绩。
