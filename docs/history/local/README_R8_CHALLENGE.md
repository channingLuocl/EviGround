## 为什么 Top-5 接近 90% 仍可能只有约 50% 定位准确率

导出分类指标按 3,413 个实例统计：exact Top-1 为 2,196/3,413（64.34%），Top-5 为 3,024/3,413（88.60%）。
Top-5 只说明正确类别出现在五个假设里，并未选定类别或实例。定位还需区分目标、参照、同类候选和空间关系。
分类按实例计数，定位按 7,805 条描述计数；同一物体可被多次描述，且定位检索使用类别别名，二者分母与匹配定义不同。

完整 7,805 条描述按目标出现频次加权后，exact Top-1 为 6,111/7,805（78.30%），
Top-5 为 7,516/7,805（96.30%）。即使目标 exact Top-1 正确，r3 首轮最终定位仍只有
3,908/6,111（63.95%）；目标类别正确并不保证参照物、同类实例区分和空间推理正确。
完整首轮结果为 4,170/7,805（53.43%），与原 GT 跨版本历史累计 69.63% 不同口径。
该分组是离线诊断，不能单独隔离类别替换的因果影响；GT 分类检查不传入推理。
详见诊断目录 `classification_vs_grounding_diagnostic.json`。

固定 323 条初版快照中，正确目标进入候选 307 条（95.05%），最终正确 159 条（49.23%）；
164 条错误中只有 16 条漏召回，另 148 条是在已召回后选错或弃答。
可按本批实际条件比例分解为 307/323 × 159/307 = 159/323，不能用分类 Top-5 直接推算最终定位。
旧 GT 历史累计在同一 323 条上为 214/323（66.25%）；它仍包含跨版本历史正确保留，不能隔离类别替换的因果影响。

固定 48 条 r3 消融中，Top-1→Top-5 将目标召回从 42/48 提至 45/48，平均目标候选从 4.29 增至 7.35，
最终正确却从 27/48 降为 23/48（改对 2 条、改错 6 条）。这是开发样本上的干扰证据，不代表 Top-5 永远较差。
原版另有清除 GT 标签后外壳剔除失效的渲染回归，已修复；观察者左右、参照绑定和数值维度仍是需验证的环节。
旧 69.63% 是 7,805 条上的历史累计成绩，初版约 50% 是部分样本单轮，不能把全部差距归因于分类器。
