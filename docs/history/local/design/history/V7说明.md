# SeeGround v7

v7 增加源文本绑定的负向颜色检查、同义类别召回、有效实例框尺寸排序和多线索暂定选择。维持 v6.2 strict schema、单次额外恢复预算、3 次取证预算和手动 null 重跑。

## 运行

```bash
local/run_local_v7.sh
```

默认 worker=2、API concurrency=2，新目录为 `local_outputs/v7_local_时间戳`。可以用 `--limit 3` 做小批验证。也可以传 `--manifest` 指定清单。

完成或中断后，重跑该 v7 目录的 null：

```bash
SEEGROUND_RUN_DIR=/绝对路径/v7_local_时间戳 local/run_local_v7.sh --retry-null
```

已有非 null 预测会跳过；前次 null 保存在 `null_retries/attempt_NNN`。代码和配置身份必须一致。不能把 v6.2 输出目录当成 v7 目录继续跑；v6.2 原入口显式关闭 v7。

## 行为

- `chalk board/chalkboard/blackboard` 统一召回；whiteboard 保持独立。解析请求可见场景类别表，但不含标注目标编号或干扰项列表。
- `big brown table not the white one` 保留 big/brown，white 绑定为同一目标的排除条件；外观请求实际收到 brown/not white。遮挡或看不清不会证明 not white。复杂 `without white legs` 继续未知。
- `section/part of table` 召回 table，保留部件原文。已有框提供体积、占地、板面代理与高度。普通 taller/shorter 用 dz；明确桌面离地条件继续走原局部地板执行器。
- 点云拟合失败或扫描不完整不再阻断有效框的暂定排序。完全并列、缺失/无效框、错误的显式比较成员数不会产生唯一极值。
- near 使用尺度相关合理范围内的距离倾向；多个可能参照的偏好一致才汇合，不认证为 nearest。corner 优先使用有限拟合墙面交点；只有一面墙或无限延长线的远处交点不算角落。on/support 继续检查接触高度与水平覆盖。
- 候选保留支持集合；明确可见矛盾具有否决权。唯一不被其他候选支持集合支配的候选可以暂定输出；不同线索相互支持不同候选时继续弃答。没有证据时不按编号破局。
- 规划前展示廉价框/关系预览；有未执行的尺寸词时，停止或第三次重复同维度会改为尺寸取证，不扩大预算。

暂定排序输出 `accepted=false`，未解决条件保留。`active_trace.v7_decision` 记录度量/来源、数值差、风险、支持集合、矛盾和关系绑定；`v7_schedule_corrections` 记录调度修正。原单候选兜底继续保留。已有全部条件通过的路径仍可 `accepted=true`。

## 验证及边界

见 [V7验证](V7验证.md)。框只是扫描观测边界；斜放膨胀、缺失扫描与标注瑕疵仍可造成错误。普通 book 默认保留体积；视觉明确解释为单本平面时允许板面框代理。复杂 facing/across、房间功能、标志内容仍可能未知。第一版尺寸框排序全部按暂定处理，记录差距不代表已完成物理实体认证。

整体基准的净正确数仍须通过固定配置配对实跑确认。减少 null 不等于准确率提高。
