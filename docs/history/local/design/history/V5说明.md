# SeeGround v5

实现目录：`/Volumes/KESU/论文/.worktrees/relative-size-evidence-v5/reproductions/SeeGround`。基线为 v4 的 `1560a17`；v4 目录不受修改。设置 `SEEGROUND_V5=1` 启用；`SEEGROUND_V5=0` 保留原 v4 行为，原模块消融开关继续可用。

## 行为变化

- 最终复核区分支持删除、反驳删除、反驳已选目标与未知；校验原句、事件、可见实例和具体条件证据。支持删除不恢复候选，反驳已选目标撤销认证；保留每样本一次共享回溯。
- 附着歧义最多计算全类别与关系子集两种解释，各自保留成员证据、未知 ID 和数量要求。未知解释不投票、不据此删除；未完成的解释保留缺口。普通诊断、参考物诊断与主动大小操作复用同一实现。
- near/by/next-to 和支撑关系供成员绑定复用；多参考物保留所有可能绑定。`with a backpack on it` 表示参考物在目标上。
- 只从已标记局部 floor/ground 点拟合水平地面；记录固定 RANSAC 参数、支撑面积、残差和离群点。桌面为宽主体水平面，多层解释或无地面支撑仍未知。
- PCA 主体平面面积保存物理方向、边界和厚度，镜子、白板、书的整体大小面积解释仍属暂定；明确轴向条件使用原指标。没有可审计的真实尺寸上下界时不创造区间，未知成员继续阻止认证。
- 最终复核使用当前 focus 实例的实际指标与质量，保留全比较范围及未知成员 ID，提供相关删除依据；相同证据版本与相机的内部视觉调用复用结果。完整扫描不能通过重复换视角假定获得。
- 外层摘要合并重复证明状态；必要时用共享证据引用和字段/行编码无损保存重复结构，保留全部原句条件、角色、数量约束、失败理由、未知候选和必要删除事件。预算记录 UTF-8 字节上界，默认上下文上限 32768、输出预留 2048；这不是精确 tokenizer 计数，可用 `SEEGROUND_CONTEXT_LIMIT` 配置服务上限。
- 解析、外层、内部视觉共享每样本一次额外 API 尝试；仅暂时故障或已改变摘要的明确上下文错误符合条件。Qwen/OpenAI/JEV 均记录实际尝试与失败成本。
- 开始复核前保存 `pending_review.json`；推理阶段保存 `pending_inference.json`，成功 API 响应按请求 hash 复用。恢复核验代码、原句、模型设置和场景 SHA-256。用完额外尝试的失败保留记录；`--retry-errors` 不重新开始整条推理。复核服务失败保留原预测，并单列 `review_failed`。

## 终端输出

三个批处理入口每条只显示：

```json
{"predicted_id": 17, "correct": true}
```

进度条在 stderr 显示已完成/总数、百分比、耗时和 ETA；普通终端原位更新，无终端输出逐次进度。`null` 表示未给出预测，`correct=false`，详细失败原因见对应 JSON。终端不追加汇总或路径；完整汇总、逐条缺口与轨迹仍保存在结果目录。
