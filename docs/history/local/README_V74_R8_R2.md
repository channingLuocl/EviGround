# r8 定位 r2：渲染、类别角色和一致性复核

这是在中断的 r1 运行上诊断得到的开发版本；不是已经证明优于 r1 的全量结果。
固定 48 条开发对照中，r1 正确 19 条，r2 正确 24 条；视角相关题退步，额外复核没有净收益。
因此目前不建议直接启动 7,805 条全量。保留独立入口供后续验证，旧入口行为不变。
分类器及其完整 Top-5 不改变，不读取 GT 类别做定位。

## 已确认的问题

2026-10-20 固定保存的 323 条运行快照中，159 条正确（49.23%），没有执行错误。
307 条已经把正确物体召回候选，但其中仍有 148 条定位错误；只有 16 条未召回。
目标类别最佳匹配为 Top-1 的 270 条中正确 146 条；靠第 2–5 名召回的 37 条正确 13 条。
视角相关描述正确 63/157（40.13%）；视角无关描述正确 96/166（57.83%）。

因此不能把主要误差归结为类别漏召回，也不能仅通过收紧 Top-5 来解决。
其中 48 条错例的 Top-1 和 Top-5 目标候选集合本来相同。
诊断文件保存在项目根目录 `outputs/r8_grounding_audit_20261020/`。

源代码层面还发现：

- 预测模式会清掉补充实例的 GT 类别，旧渲染器却按 `wall/ceiling` 类别隐藏外壳，导致清掉标签后失效。
- 两个全景视图里候选偏小、遮挡多；没有给每个候选独立的类别/外观视图。
- 目标和参照的类别备选缺少显式角色匹配表，所有对象五个标签造成干扰。
- 某些回答读反数值顺序，或者把拍摄相机的左右当成描述者左右。
- 初版 r2 小样本中还出现嵌套名词误解析，如“桌子上有盒子”被解析成找盒子；该例原 r1 解析为桌子。

## r2 的改动

1. 按分类器覆盖的实例 ID 渲染，不依赖已清掉的 GT 外壳标签；匿名补充实例只保留几何，不暗中恢复其类别。
2. 相机按视锥拟合范围；增加俯视图和覆盖所有目标候选的分页独立视图。
3. 原始预测文件和检索保留完整 Top-5；发送到当前查询的表只保留 Top-1 及匹配目标/参照的相关备选。
4. 显式标记 Top-1 类别匹配和备选类别匹配；不把所有类别等权，也不直接丢弃备选候选。
5. 补充所有候选到各参照的三维/水平中心距和框间距，以及数值排序；不把距离自动等同于语言谓词。
6. 给解析器提供从原句开头名词提取的提示；多分句或不明确的句式不强制改写。
7. 场景初选后增加一次完整描述/数值/类别角色一致性复核；保存初选和复核结果。

复核仍然由同一个模型完成，不是数学证明，也不代表独立错误过程。
每个进入场景定位的查询会增加一次 API 调用；较多候选还会增加图片输入和本地渲染耗时。
保留全部候选与 `null` 选项，复核不能选中排除的 ID。

## 验证方式

第一轮仅含渲染/数值输入改动的 24 条开发诊断：r1 正确 10 条，初版 r2 正确 11 条。
随后补充名词提示和一致性复核，在固定 48 条上验证：

| 指标 | r1 | r2 |
| --- | ---: | ---: |
| 正确数 / 查询数 | 19/48 | 24/48 |
| 定位准确率 | 39.58% | 50.00% |
| 目标候选召回 | 45/48 | 45/48 |
| 视角相关题正确数 | 10/25 | 8/25 |
| 视角无关题正确数 | 9/23 | 16/23 |
| 实际 API 请求次数 | 98 | 146 |
| 总 token | 1,118,822 | 1,973,658 |
| 平均单条流水线耗时 | 15.41 秒 | 22.78 秒 |

配对改对 7 条、改错 2 条，净增 5 条（10.42 个百分点）。初选和最终复核均正确 24 条；
复核把 CSV212 改对，把 CSV67 改错，额外消耗 48 次调用和 928,317 token，未显示净收益。
总 token 增加 76.4%；这是用量，不是按价格计算的账单。
两次并发不同（r1 workers10/API8；r2 workers4/API4），耗时不属于严格速度对照。
r2 本轮总墙钟耗时约 292 秒，无执行错误，全部选择位于允许候选集合内。

初始 24 条为 10→11，新增 24 条为 9→13；这两组都是开发诊断，不能解释为独立留出验证。
全部 48 条的解析目标类别和候选召回状态在 r1/r2 间相同，因此不能把本轮净提升归因于修复目标解析。
CSV1840 的错误目标解析出现在初版 r2；本轮已恢复 desk 并选中正确桌子，但 r1 本来也解析为 desk。

完整结果及配对增损：项目根目录 `outputs/r8_grounding_audit_20261020/paired48_comparison.json`。
可读诊断：同目录 `REPORT.md`；重建统计：同目录 `build_paired48_report.py`。
样本均来自已暴露的旧运行快照，按位置选取，没有按正确性筛选，但不能当独立盲测或全量提升。
配对增损的双侧精确检验 p=0.1797；样本证据不足以断言稳定改善。
开发比较允许代码有意不同，不使用要求代码完全一致的 Top-1/Top-5 消融比较脚本。

剩余问题仍包含数值维度读错、观察者左右与世界坐标混淆；同模型再复核一遍不能保证纠正。
旧 GT v7.4 结果使用过 `cumulative_ever_correct` 并混有实现版本，不能直接当本次单轮预测类别实验的公平基线。
停止后的 342 条记录中有 8 条 SIGINT 中断错误，应与模型选错区分；323 条固定快照不含这些错误。
