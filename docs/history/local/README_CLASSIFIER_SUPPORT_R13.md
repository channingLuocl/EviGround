# 训练支持度与房间平衡 r13

在既有冻结四视图CLIP512特征上，训练零初始化的语义残差头。支持度缩放和类别内房间重加权形成四组对照，三个随机种子，每组40轮。支持度、房间权重只由28730训练对象计算。

沿用404验证选型、锁定完整75行网格后才评估3413历史对象的流程。OOV计错；True与Exact分开；历史评估已经暴露，不能称独立盲测。所有锁定、纯模型和回退结果均报告，不根据历史成绩重选。

运行器为 `classifier_support_r13.py`，独立复算器为 `audit_classifier_support_r13.py`。阶段依次为 `preflight`、`train-select`、`evaluate`，参数为 `--output --reference --r4 --r8 --design`。审计器不需要design参数。

正式运行前先完成32个TRAIN对象、各20步的学习/冻结buffer/NumPy前向检查；完成后复算全部训练支持度、24个头前向、75行选型、84条结果以及物理房间bootstrap。训练日志的loss是批次归一化loss的对象数加权平均，不是整体加权损失的严格重算。

依赖队列等待r12成功后启动。数据、架构、超参和选型规则在排队前封存；不使用r11/r12新分数修改本轮设计。r13并非新的主干预训练，也不主张该组合为首创。
